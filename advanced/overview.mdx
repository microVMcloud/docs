These guides deploy minlin apps that need more memory than the Trial plan allows. You build each app's disk image on your own Linux machine, upload it, and boot it with the public minlin kernel.

| Guide | What it runs | RAM |
| --- | --- | --- |
| [Caddy](/advanced/caddy) | Caddy web server | 64 MiB |
| [Tailscale](/advanced/tailscale) | Tailscale node, optionally an exit node | 64 MiB |
| [Lightpanda](/advanced/lightpanda) | Headless browser as an MCP server | 128 MiB |

<Note>
  The Trial plan allows at most 32 MiB of RAM per VM. [Add funds](/microvm/billing) to move to the prepaid plan before you start.
</Note>

## Before you start

Each guide assumes you have:

- A prepaid account at [microvm.cloud](https://microvm.cloud).
- An x86-64 Linux host with the minlin disk build tools. See [Build and boot prerequisites](/minlin/build-and-boot#prerequisites).
- A clone of the minlin repository:

```bash
git clone https://github.com/microvmcloud/minlin.git
cd minlin
```

You don't need to build the kernel. The public minlin kernel already includes what these apps need.
