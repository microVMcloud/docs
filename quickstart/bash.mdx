---
title: "Create a Bash microVM"
description: "Launch a Bash microVM with public minlin and bash images in the microVM Cloud dashboard."
---

Use a public minlin kernel and a `bash` disk image to create a microVM running Bash. Use this to create a simple instance where you can download software as needed with `curl`/`wget`.

## Prerequisites

You need a trial or prepaid account. [Sign up at microvm.cloud](https://microvm.cloud) if you do not have one.

## Create and use your microVM

<Steps>

  <Step title="Create a new microVM">

    Note: Image names can include version numbers. Choose the latest if there are multiple versions.

    Open **VMs** and click **New VM**.

    - In **Name**, enter `bash-server`.
    - In **Kernel image**, select the latest public `minlin 7.3.6` Linux kernel.
    - Under **Memory**, keep the **RAM (MiB)** value selected by the form, which is at least 32 MiB for Linux. Optionally, set **Swap (MiB)** at `32`.
    - Under **Storage**, keep **Disk** set to **From disk image** and select the public `bash` disk image.
    - All other parameters (App arguments, SSH keys, and HTTPS hostname can remain at their defaults)
    - Click **Create VM**

    The dashboard opens your VM's detail page. Wait for its status to become `running`.

  </Step>

  <Step title="Connect via the VM serial console">

    Scroll down to the **Console** section in your VM details page.

    The **Console** section displays the guest's serial output. Click **Refresh** to fetch output, or enable **auto-refresh** to follow it. **auto-scroll** keeps the latest output visible. Drag the console's corner to resize it.

    While the VM is running, type into the input field and press Enter or click **Send**. The console sends the text and an Enter key to the guest.

    The **Ctrl+C**, **Ctrl+D**, **Ctrl+Z**, and **Ctrl+\** buttons send control characters. In the input field, Ctrl+C with no selection and Ctrl+D also go to the guest.

    Click **Clear** and confirm to permanently empty the console log.

  </Step>

  <Step title="Install your software / scripts">

    From the command line you can pull software with `curl`/`wget` as needed.

  </Step>

</Steps>

For more VM settings and controls, see [VMs](/microvm/vms). To use your own kernel or disk, see [Images](/microvm/images).
