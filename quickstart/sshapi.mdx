---
title: "Create a SSH microVM via the API"
description: "Launch a SSH microVM with public minlin and sshd images via the microVM Cloud API."
---

Use a public minlin kernel and an `sshd` disk image to create an SSH server.

## Prerequisites

You need a trial or prepaid account. [Sign up at microvm.cloud](https://microvm.cloud) if you do not have one.

## Create and connect to your microVM

<Steps>

  <Step title="Get API key">
  
    Sign in to the [dashboard](https://microvm.cloud) and open **API & Keys**. Under **API keys** enter a Name and click **Create key**. The key will be displayed. Copy it somewhere secure.

  </Step>

  <Step title="Prepare API script">

    ```bash
    curl -fsSLo microvmcloud https://microvm.cloud/cli/microvmcloud && chmod +x microvmcloud
    ```
    
  </Step>

  <Step title="Login with your API key">

    ```bash
    ./microvmcloud login
    ```

    Paste in your API key from the previous step.

  </Step>

  <Step title="Upload your SSH public key">

    <Warning>
      Never share your private SSH key. You only need to provide the public one.
    </Warning>

    ```bash
    ./microvmcloud ssh-key add <file.pub> --name MySSHKey
    ```

    Substitute the `file.pub` filename as needed.

    Use the contents of a `.pub` file, such as `~/.ssh/id_ed25519.pub`. If you need a key, generate one in your local terminal:

    ```bash
    ssh-keygen -t ed25519
    ```

  </Step>

  <Step title="Configure and start the VM">

    ```bash
    ./microvmcloud vm create "SSH VM" --kernel "minlin 7.3.5" --ram 32 --swap 32 --no-https --disk-image "openssh 10.5p1" --ssh-key MySSHKey
    ./microvmcloud vm wait "SSH VM" running && ./microvmcloud vm show "SSH VM"
    ./microvmcloud vm console "SSH VM" --follow
    ```

    Make note of the `Hostname:` value. it should be in the format `vmXXXXX.nodeXXXXX.microvmcloud.online`

    Use `Ctrl+C` to exit the VM console.

  </Step>

  <Step title="Forward the SSH port">

    ```bash
    ./microvmcloud vm forward-add "SSH VM" tcp 22 20005
    ```

  </Step>

  <Step title="Connect over SSH">

    ```bash
    ssh -p <public-port> root@<vm-hostname>
    ```

    On your first connection, check that the host-key fingerprint matches the fingerprint shown on the VM page before accepting it.

    For connection checks, see [Connect over SSH](/microvm/networking#connect-over-ssh).
  </Step>

</Steps>

For more VM settings and controls, see [VMs](/microvm/vms). To use your own kernel or disk, see [Images](/microvm/images).
