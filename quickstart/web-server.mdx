---
title: "Create a web server microVM"
description: "Launch a web server microVM with public minlin and lighttpd images in the microVM Cloud dashboard."
---

Use a public minlin kernel and a `lighttpd` disk image to create a web server.

## Prerequisites

You need a trial or prepaid account. [Sign up at microvm.cloud](https://microvm.cloud) if you do not have one.

## Create and use your microVM

<Steps>

  <Step title="Create a new microVM">

    Note: Image names can include version numbers. Choose the latest if there are multiple versions.

    Open **VMs** and click **New VM**.

    - In **Name**, enter `web-server`.
    - In **Kernel image**, select the latest public `minlin 7.3.6` Linux kernel.
    - Under **Memory**, keep the **RAM (MiB)** value selected by the form, which is at least 32 MiB for Linux. Optionally, set **Swap (MiB)** at `32`.
    - Under **Storage**, keep **Disk** set to **From disk image** and select the public `lighttpd` disk image.
    - In **HTTPS hostname**, select **nginx handles HTTPS → guest port 80 (HTTP)**. The platform handles HTTPS for the VM's hostname and passes plain HTTP to the web server on guest port `80`.
    - All other parameters (App arguments, SSH keys)
    - Click **Create VM**

    The dashboard opens your VM's detail page. Wait for its status to become `running`.

  </Step>

  <Step title="Open your website">
    Wait for the VM's status to become `running`. Its hostname appears after the platform assigns it to a host.

    Under **Details**, click the **Hostname** link. It has the form `vm<id>.node<id>.microvmcloud.online` and opens your web server's page in a new tab.

    If the website does not load, find **Console** on the VM page and click **Refresh** to check the server's output. See [Help and troubleshooting](/microvm/help#the-hostname-does-not-load-the-application) for more checks.

  </Step>

</Steps>

For more VM settings and controls, see [VMs](/microvm/vms). To use your own kernel or disk, see [Images](/microvm/images).
