Launch your first microVM from public images in the [microVM Cloud dashboard](https://microvm.cloud). Choose the guide for the server you want to create.

<Card title="Create a Bash microVM" icon="terminal" href="/quickstart/bash">
  Launch a Bash instance with the public minlin kernel and `bash` disk image.
</Card>

<Card title="Create a SSH microVM" icon="terminal" href="/quickstart/ssh">
  Launch a SSH server with the public minlin kernel and `sshd` disk image, then connect with your SSH key.
</Card>

<Card title="Create a web server microVM" icon="globe" href="/quickstart/web-server">
  Launch a web server with the public minlin kernel and `lighttpd` disk image, then open its HTTPS hostname.
</Card>

<Card title="Create a SSH microVM via the API" icon="terminal" href="/quickstart/sshapi">
  Launch a SSH server with the public minlin kernel and `sshd` disk image via the API script, then connect with your SSH key.
</Card>
