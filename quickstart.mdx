---
title: "Quickstart"
description: "Launch an SSH or webserver microVM from public images in the microVM Cloud dashboard."
---

Use a public minlin kernel with an `sshd` disk image to create an SSH server, or the `lighttpd` disk image to created a web server. Follow the section for the VM you want to create.

## Prerequisites

You need a trial or prepaid account. [Sign up at microvm.cloud](https://microvm.cloud) if you do not have one.

## Create a SSH microVM

<Steps>
  <Step title="Save your SSH public key">
    Sign in to the [dashboard](https://microvm.cloud) and open **API & Keys**. Under **SSH keys**, paste your public key into **Public key**, optionally enter a **Name**, and click **Add key**.

    Use the contents of a `.pub` file, such as `~/.ssh/id_ed25519.pub`. If you need a key, generate one in your local terminal:

    ```bash
    ssh-keygen -t ed25519
    ```

    Paste only the public key. Keep the private key on your computer.
  </Step>

  <Step title="Open the New VM form and choose images">
    Open **VMs** and click **New VM**.

    - In **Name**, enter `ssh-server`.
    - In **Kernel image**, select the public minlin Linux kernel.
    - Under **Storage**, keep **Disk** set to **From disk image** and select the public `sshd` disk image.

    Image names can include version numbers. Choose the available minlin kernel and `sshd` disk image; you do not need specific versions for this guide.
  </Step>

  <Step title="Configure and start the VM">
    Keep the **RAM (MiB)** value selected by the form, which is at least 32 MiB for Linux. Leave **Swap (MiB)** at `0` and **App arguments** empty.

    Under **SSH keys for root**, select the public key you saved. The platform installs it before the first boot.

    Clear **HTTPS hostname** and keep **Start after creating** selected. Review the hourly estimate, then click **Create VM**.

    The dashboard opens your VM's detail page. Wait for its status to become `running`.
  </Step>

  <Step title="Forward the SSH port">
    Under **Port forwarding**, select **TCP** for **Protocol** and enter `22` for **Guest port**. Leave **Public port** empty so the platform assigns one, then click **Add**.
  </Step>

  <Step title="Connect over SSH">
    Under **Details → SSH**, copy the connection command and run it in your local terminal. It has this form, using your VM's assigned public port and hostname:

    ```bash
    ssh -p <public-port> root@<vm-hostname>
    ```

    On your first connection, check that the host-key fingerprint matches the fingerprint shown on the VM page before accepting it.

    For connection checks, see [Connect over SSH](/microvm/networking#connect-over-ssh).
  </Step>
</Steps>

## Create a webserver microVM

<Steps>
  <Step title="Open the New VM form">
    Sign in to the [dashboard](https://microvm.cloud) and open **VMs**. On the **Virtual machines** page, click **New VM**.
  </Step>

  <Step title="Name the VM and choose a kernel">
    - In **Name**, enter `web-server`.
    - In **Kernel image**, select the public minlin Linux kernel. Its option includes **Linux** and the image size.

    Image names can include version numbers. Choose the available minlin kernel; you do not need a specific version for this guide.
  </Step>

  <Step title="Configure memory and storage">
    Under **Memory**, keep the **RAM (MiB)** value selected by the form. Selecting a Linux kernel raises it to at least 32 MiB. Leave **Swap (MiB)** at `0`.

    Under **Storage**, use these settings:

    | Field | Selection |
    | --- | --- |
    | **Disk** | **From disk image**, selected automatically for Linux |
    | **Disk image** | The public lighttpd image |

    The disk image contains the web server and its files. Each VM gets its own copy.
  </Step>

  <Step title="Create and start the VM">
    Leave **App arguments** empty and **SSH keys for root** unselected. You do not need SSH for this example.

    Keep both checkboxes selected:

    - **HTTPS hostname** routes the VM's HTTPS address to the web server on guest port `80`.
    - **Start after creating** starts the VM automatically.

    Review the hourly estimate, then click **Create VM**. The dashboard opens your VM's detail page.
  </Step>

  <Step title="Open your website">
    Wait for the VM's status to become `running`. Its hostname appears after the platform assigns it to a host.

    Under **Details**, click the **Hostname** link. It has the form `vm<id>.node<id>.microvmcloud.online` and opens your web server's page in a new tab.

    If the website does not load, find **Console** on the VM page and click **Refresh** to check the server's output. See [Help and troubleshooting](/microvm/help#the-hostname-does-not-load-the-application) for more checks.
  </Step>
</Steps>

For more VM settings and controls, see [VMs](/microvm/vms). To use your own kernel or disk, see [Images](/microvm/images).
